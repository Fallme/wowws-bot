# 开局原生航行与 Q/E 接管

## 控制流程

| 状态 | 处理 |
| --- | --- |
| 开局建立航线 | 沿用 M 地图设置航点与有界重试；明确识别“自动驾驶启用”后保留确认状态 |
| 原生航线正常 | 不发送常规 W/Q/E，继续观察位置、航速和目标；消耗品独立处理 |
| 航点稳定抵达 | 沿用连续三次新鲜位置确认，先校准实际舵位和油门，再切换 Q/E |
| 开局设置失败 | 确认退出战术地图后，校准油门/舵位再接管，避免缓存与游戏实际档位不一致 |
| 原生文字仍在但停船 | 起步宽限 30 秒后，航速不高于 1.5 节且新鲜位置连续 20 秒不变才接管；单次低速或无定位不触发 |
| 原生文字消失 | 保留原有文字多帧确认加持续低速接管；仍在正常航行时不因一次 OCR 漏读撤销航线 |
| 已发现稳定敌舰或预测岸线危险 | 沿用已确认地形、新鲜船位与敌舰连续确认条件，交给 Q/E 避障接敌 |
| 接管之后 | 本局标记原生航线已放弃，不因残留绿色文字再次启用；重复接管请求不重复打舵 |
| 用户介入或战斗结束 | 沿用现有暂停和场景识别门禁；停船计时不跨越长观测中断累积 |

校准过程使用既有键盘控制器：四次 Q 到左满舵，再两次 E 回中；W 确保前进全速。此动作校准的是锁定档位，船舵和船身仍存在响应时间，不能认为按完即停止转动。

## 实测反馈接入

- 五档 Q/E 锁舵沿用既有控制器和 HelmModel。
- 波美拉尼亚 `qe_turn_speed_retention: 0.76`，来自约 23.4 / 30.8 节的画面观察；其他船不据此假装已标定。
- 从新鲜小地图船头方向估计角速度，处理正负 180 度环绕，拒绝大跳变，三秒未更新即失效。
- 航迹预测加入角速度惯性：回中后仍会转动；对准目标但仍在旋转时可提前反打半舵，减小过冲。
- `qe_yaw_response_seconds: 4.0` 是待标定的响应初值。15 秒打舵时间、1 公里半径、地图边长仍需对应船只和地图进一步校准。

位置停滞判断使用归一化地图位移阈值 0.0015，要求连续观测间隔不超过五秒；缓存船位、缺失航速或长间断会清空证据。它优先避免误接管，无法定位时不强行认定原生航线失败。

此次为代码接入与离线回归验证，未自动启动新的实战。核心回归覆盖残余转向反打舵、档位校准只执行一次、确认 HUD 仍停船时接管、起步宽限、缓存位置和观测间断。
