# Q/E 驾驶调研与实现

调研日期：2026-09-06。适用 PC 版；不是 Legends/Blitz，也没有调用游戏内部驾驶 API。实际接入现有截图识别和 Windows Q/E 输入。

## 已核实的机制

- Q/E 对应满左、半左、中舵、半右、满右五档。按一次改变一档，松开不回中；反向按键才改变设定。保留现有输入器的档位差分发送。
- 港口转弯半径描述持续满舵、稳定转弯时的表现，并非从直航刚开始打舵就能走出的圆。转弯会损失航速；普通 BB/巡洋舰可分别以约 0.75/0.80 的保速率作为初值，特殊舰船除外。
- 减速不是瞬停，也不是越慢越好转；不能用低油门立即替代碰撞预测。

来源：[官方 Wiki 操舵说明](https://wiki.worldofwarships.com/Ship%3AManeuvering)。Wiki 不是逐版本精确动力学规范。

地图有不同实际边长，例如 Ocean 36 km、部分地图 42 km，因此不能把所有地图的十格网格都当作每格 5 km。来源：[官方 Wiki 地图表](https://wiki.worldofwarships.com/Ship%3AMaps)。

公开客户端逆向记录给出船模单位到引擎单位 1/15、引擎单位到距离米 30、运动时间因子 2.61。本项目据此推导距离口径的速度因子为 `(30/15)*2.61=5.22`，30 节约对应地图距离 0.08056 km/s。它是工程初值，不是官方保证，优先以本局实测位置校正。来源：[作者原始逆向记录](https://github.com/landaire/wows-toolkit/blob/main/docs/BALLISTICS.md#5-coordinate-system)。

## 本次修改

1. `strategy/helm_model.py` 跟踪实际估计舵位：指令先量化到五档，再随时间移动；接令不等于已到满舵。预测使用该估计值，包含反舵回中所需时间。紧急避山直接下反舵，取消额外的 0.65 秒软件等待，实际舵仍渐变。
2. 连续新鲜小地图位置以不少于 3 秒的窗口估速，拒绝不合理跳点，超过 5 秒不再使用旧速度；不将缓存定位当新样本。转弯减速采用可调保速率和 12 秒一阶响应近似，尚不是实船拟合结果。
3. 两艘预设启用敌舰优先。中央点作为无敌舰时的目标；绕岛航点和碰撞预测优先于追敌，开局也不例外。原生自动航行至少经过配置的开局时间、连续确认敌舰且有山体后交接；预测危险可提前交接。
4. 占领圈仅屏蔽圆周和中央标记，保留圈内山体；缩小玩家标记屏蔽区。海岸多边形保留全部简化顶点，不再直接截成12点，减小岬角被切掉的风险。
5. 使用45秒局部航迹窗口、五个可执行舵档、亚像素积分采样，保留岸线安全净空和地图边界约束。进入副炮接战距离后降至3/4油门。

## 配置与校准

修改 `config/ship.yaml` 对应舰船的 `strategy`：

| 参数 | 当前值/含义 |
|---|---|
| pursue_enemies | true，敌舰优先；false恢复旧中央点策略 |
| map_span_km | 50是未校准初值，必须按本局地图实际边长设置 |
| qe_speed_scale | 5.22，实测速度不可用时的估算因子 |
| qe_speed_knots | 波美30；那不勒斯保留已有36节配置 |
| qe_rudder_shift_seconds | 15，中舵到满舵的模型时间 |
| qe_turning_radius_km | 1.0，地图距离口径下的稳定满舵半径 |
| qe_turn_speed_retention | 可选；默认BB为0.75，其他为0.80 |
| qe_prediction_horizon_seconds | 45 |
| qe_safety_clearance_km | 0.45，包含舰体与识别误差的保守包络 |

**15秒口径尚未核实到足够可靠的PC版原始资料。** 若用户提供的15秒实际是满左至满右，那么模型的中舵至满舵应填7.5秒。不要未经计时就直接套用。港口标称1km也不应未经测量便当作地图坐标半径；本次保留用户初值。

训练房测量步骤：

1. 核实地图名称/边长，固定小地图缩放和完整地图裁剪范围，尽量关闭不必要的覆盖层。不要同时启用会改舵的第三方/游戏辅助功能。
2. 空旷海面全速直航，记录至少4组时间、归一化位置、舰首角度、HUD节数，间隔3秒以上。
3. 另开一个样本文件记录稳定满舵段；与直航段分开。用画面中的舵位指示计时中舵至满舵、满左至满右，单独填写响应时间。
4. 用离线脚本估计速度因子与稳定转弯半径；样本中的heading_degrees为屏幕向右0°、顺时针为正。

```powershell
cd E:\aimemo\wowws-bot
.\.venv\Scripts\python.exe tools\calibrate_navigation.py E:\aimemo\tmp\ship_samples.csv --map_span_km 42
```

CSV列：`time_seconds,x,y,heading_degrees,speed_knots`。工具只输出建议JSON，不按键、不自动改配置。

## 验证范围与剩余限制

测试覆盖渐变舵位、反舵、速度缩放、定位跳点、占领圈内山体、敌舰优先、避障优先以及已有截图回归；另需训练房实测确认碰撞率和进入副炮范围耗时。

目前没有自动识别地图名称/比例尺，未实现完整的加减速与漂移辨识、敌舰运动预测、友舰动态避让、全局最短航路、逐舰炮线遮挡评估。局部航迹与颜色分割不能保证零撞山；半透明地图、未识别海岸、狭窄水道和舵机损坏仍需实测。山体来自多帧视觉轮廓，不是官方碰撞网格。实测航速可以修正运动估算，但不能代替正确地图比例尺。
