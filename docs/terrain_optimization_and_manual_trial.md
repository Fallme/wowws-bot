# 小地图优化与直接驾驶测试（2026-09-06）

## 已实现

- 保留 RapidOCR 和 PP-OCRv4，未更换 OCR 模型、依赖或服务。
- 将整座岛的中心/面积匹配改为 512 像素归一化地图上的逐像素投票，最近五次观测中至少三次确认才作为陆地。
- 本局确认地图每 15 个控制 tick 低频补全，保留之前确认的陆地，避免图标遮挡让已确认的岸线消失。大幅不重合的新观测不合入模板。
- 只在界面遮挡区域修补小缺口，不对可见水道进行闭运算；利用实体厚度排除细射程圈残片。
- 降低小岛过滤门槛、提高轮廓数量上限。已经确认的近船岸线不再被船标排除圆抹掉。

模板仅在本局使用，沿用本局重置逻辑。尚未建立跨地图模板库，未实现自动地图身份识别、缩放/平移配准；重合检查不能代替这些能力。永久保留确认陆地仍有积累持续误检的风险。外轮廓表示对封闭内湖较保守。
