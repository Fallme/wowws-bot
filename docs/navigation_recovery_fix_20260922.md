# 小地图自适应与流程阻塞修复（2026-09-22）

## 变更

- 小地图使用右下角实际十格网格定位，不再只对 1440 高度启用校准。搜索范围不作为最终地图范围；小地图大小可独立于窗口分辨率变化。每两秒重新检查，网格证据丢失超过四秒不沿用旧校准。
- 地图范围、来源或尺寸变化时，清理旧山体、占领点、路线、船位、航速及转向率缓存，重新采样。无网格证据时仍有低置信度比例裁切回退，不保证所有主题或遮挡都可恢复校准。
- 占领圈取消 680 像素宽度分支，按圆周角度覆盖和中性/队伍颜色验证；不把黄色射程圈当占领点，也不猜测遮挡的点位字母。
- 地形补全要求足够的轮廓重叠；A* 起点可放宽水域安全余量，但不能清除实际陆地。路线平滑不能穿过陆地对角接缝。
- 舵效模拟遇到实际陆地/地图边界立即结束该候选航迹，拒绝非有限运动数值。全部候选不满足净空时减速转向，不宣称已找到安全航迹；保留原生自动驾驶控制权规则。
- 结算资源明确、高置信度识别为零时可参与多帧共识；空白或低置信度零不算成功。已确认但未读出的收益最多重试五轮；已知评价/菜单可安全关闭，仍失败则保留页面、停止续局，不跳过收益。
- 未知/战后广告页的三次 Esc 预算跨恢复调用累计，普通加载页不消耗该预算。停止请求在启动等待和内部操作前检查。
- 最后一分钟接管需要计时递减和额外开战证据；短准备倒计时不能单凭 HUD 开始驾驶。

## 验证与限制

全量自动回归使用保存截图和模拟输入，没有开启实战。多分辨率测试覆盖 1366×768、1920×1080、2560×1440、3840×2160、1600×1200、3440×1440，以及同分辨率不同地图大小；真实截图另覆盖 0.75、1.0、1.5 倍缩放。

未知广告未找到可信关闭控件时只做有限恢复并报告失败，不盲点按钮。运动模型与离线测试不能替代不同电脑上的实战验证；本轮没有宣称所有 UI 页面均已完成锚点化，也没有修改账号/任务队列设计文档。
