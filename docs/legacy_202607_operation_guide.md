# WoWS 战舰世界 - 完整操作指南

> 本文档基于641张游戏截图分析整理，涵盖港口、战斗、结算、加载等所有界面。
> 供VLM模型训练和自动化控制参考。

---

## 一、游戏状态流转

```
登录 → 港口 → (加入战斗) → 匹配/加载 → 战斗 → 结算 → 港口 → ...
```

| 状态 | 特征 | 持续时间 |
|------|------|----------|
| **login** | 账号创建/登录对话框，模糊背景 | 手动操作 |
| **port** | 3D港口场景，橙色"加入战斗"按钮 | 等待用户 |
| **matchmaking** | 匹配中，显示"正在寻找对局" | 10-60秒 |
| **loading** | 加载画面，队伍列表，风景背景 | 5-15秒 |
| **battle** | 海战场景，HUD完整显示 | 10-20分钟 |
| **results** | 结算画面，战绩统计 | 等待用户操作 |

```
┌─────────────────────────────────────────────────────┐

│                                                     │
│  ┌──────┐                              ┌─────────┐ │
│  │罗盘  │     3D港口场景                │ 船长    │ │
│  │图标  │     (选中的战舰)              │ 头像    │ │
│  │      │                              ├─────────┤ │
│  ├──────┤                              │ 船长    │ │
│  │任务  │                              │ 信息    │ │
│  │面板  │                              │ 面板    │ │
│  └──────┘                              └─────────┘ │
├─────────────────────────────────────────────────────┤

### 2.2 关键UI元素

| 位置 | 元素 | 颜色 | 功能 |
|------|------|------|------|
| 顶部中央 | **加入战斗**按钮 | 橙色/黄色 | 开始匹配对局 |
| 左上 | 罗盘/徽章 | 装饰性 | 游戏标志 |
| 左侧 | 任务面板 | 蓝/绿色卡片 | 显示每日任务/作战任务 |
| 右上 | 船长头像 | 圆形框 | 显示当前船长 |
| 右侧 | 船长信息 | 深色面板 | 船长技能/经验信息 |
| 底部 | **舰船列表** | 多色卡片 | 选择不同战舰 |

### 2.3 港口操作

| 操作 | 按键/方式 | 说明 |
|------|-----------|------|
| 加入战斗 | 点击橙色按钮 | 位于顶部中央 |
| 选择战舰 | 点击底部舰船列表 | 左右滑动选择 |
| 返回 | Escape | 返回上一级 |

### 2.4 状态识别特征

- ✅ 橙色按钮在顶部 (ratio > 0.01)
- ✅ 底部有舰船列表 (多色小图标)
- ✅ 无小地图 (minimap区域无红色)
- ✅ 无准星 (center对比度低)
- ❌ 不应有队伍面板 (左右两侧无大量色条)

│  检测中                                         ▲   │
│  [准星]  ···→ 敌舰标记              [小地图]   │   │  ← 中央准星+小地图

```

### 4.2 顶部区域 - 队伍面板与计时器

#### 己方队伍 (左上角)
| 元素 | 颜色 | 说明 |
|------|------|------|
| 队伍列表 | 绿色/蓝色条 | 12名玩家 |
| 舰船图标 | 按类型着色 | BB/CA/CL/DD/CV |
| 玩家名称 | 白色文字 | 玩家ID |
| 血量状态 | 绿→黄→红 | 存活/受伤/濒死 |
| 已沉没 | 灰色/删除线 | 已阵亡玩家 |

**舰船类型图标:**
- □ 战列舰 (BB) - 方形
- ◇ 巡洋舰 (CA/CL) - 菱形
- △ 驱逐舰 (DD) - 三角形
- ○ 航母 (CV) - 圆形

#### 计时器 (顶部中央)
- 显示: `MM:SS` 格式
- 颜色: 白色文字
- 倒计时: 从20:00开始

#### 敌方队伍 (右上角)
- 布局与己方对称
- 红色标记表示敌人
- 已沉没的敌人显示为灰色

### 4.3 左侧区域 - 检测与聊天

| 位置 | 元素 | 说明 |
|------|------|------|
| 左上 | 检测状态图标 | 👁️ 被发现 / 隐身状态 |
| 左中 | 聊天面板 | 团队/全体聊天 (可折叠) |
| 左下 | 弹药选择 | AP/HE切换 |

### 4.4 右侧区域 - 伤害日志与小地图

#### 伤害日志 (右上)
- 显示: 造成的伤害累计
- 格式: `伤害: XXXXX`
- 颜色: 白色/黄色

#### 小地图 (右下角) ⭐最重要

```
┌─────────────────┐
│  🟢🟢            │  ← 己方 (绿色/蓝色)
│     🟢           │
│        🔴🔴      │  ← 敌方 (红色)
│  🟢    🔴  ⛵   │  ← 玩家 (白色三角)
│           🔴🔴   │
│  ≈≈≈≈≈≈≈≈≈≈≈   │  ← 海面 (蓝色)
│  ████████       │  ← 岛屿 (棕色)
└─────────────────┘
```

**小地图颜色编码:**
| 颜色 | 含义 |
|------|------|
| 🟢 绿色/蓝色点 | 己方舰船 |
| 🔴 红色点 | 敌方舰船 (可见) |
| 🟡 橙色/黄色 | 目标点/占领区 |
| ⬜ 白色三角 | 玩家自己的船 |
| 🔵 蓝色区域 | 海面 |
| 🟤 棕色区域 | 岛屿/陆地 |
| ⭕ 圆圈 | 射程/检测范围 |

**小地图关键信息:**
- 敌人位置和移动方向
- 岛屿分布 (障碍物)
- 占领区状态
- 己方队友位置
- 玩家航向 (白色箭头)

### 4.5 底部区域 - 舰船状态

#### 武器与弹药 (左下)
| 按键 | 功能 | 说明 |
|------|------|------|
| 1 | 切换HE弹 | 高爆弹，对驱逐舰/上层建筑有效 |
| 2 | 切换AP弹 | 穿甲弹，对战列舰/巡洋舰侧舷有效 |
| 3 | 鱼雷 | 切换到鱼雷发射模式 |

#### 消耗品 (底部中央)
| 按键 | 功能 | 冷却时间 |
|------|------|----------|
| 4 | 烟雾弹 | ~120秒 |
| 5 | 损管维修 | ~60秒 |
| 6 | 水听/雷达 | ~120秒 |
| 7 | 战斗机 | ~180秒 |

#### 航速控制 (左下)
| 按键 | 功能 |
|------|------|
| W | 加速 (每按一次升一档) |
| S | 减速 (每按一次降一档) |

**档位对应速度:**
| 档位 | 速度比 | 说明 |
|------|--------|------|
| 0 | 0% | 停车 |
| 1 | 1/4 | 慢速 |
| 2 | 1/2 | 巡航 |
| 3 | 3/4 | 快速 |
| 4 | 全速 | 最大速度 |
| 5 | 全速+ | 增压 (部分舰船) |

#### 舵角控制
| 按键 | 功能 |
|------|------|
| A | 左转 (按住持续转) |
| D | 右转 (按住持续转) |

#### 血量显示 (底部中央)
- 格式: `❤️ HP: XXXXX/XXXXX` 或百分比
- 颜色: 绿色(健康) → 黄色(受伤) → 红色(濒死)
- 蓝色血条: WoWS使用蓝/青色血条 (H=85-125)

### 4.6 中央区域 - 准星与瞄准

#### 准星类型
- **标准准星**: 十字线 + 距离刻度
- **望远镜模式**: Shift键切换，放大视野

#### 目标锁定
- **Ctrl**: 锁定/解锁目标
- **准星对准敌人**: 自动显示距离和角度
- **前置量**: 根据敌人速度和距离自动计算

#### 射击指示
- **白色弧线**: 炮弹轨迹
- **命中反馈**: 命中时有视觉/音效反馈
- **起火/进水**: 敌方被击中后的状态

### 4.7 特殊状态

#### 被检测状态
| 状态 | 图标 | 说明 |
|------|------|------|
| 被发现 | 👁️ 红色眼睛 | 敌方可见你 |
| 隐身 | 无图标 | 敌方不可见 |
| 隐身被打破 | ⚠️ | 开火后短暂暴露 |

#### 舰船状态
| 状态 | 表现 | 处理 |
|------|------|------|
| 起火 🔥 | 船体冒烟/火焰 | 按5维修 |
| 进水 💧 | 船体倾斜 | 按5维修 |
| 模块损坏 | 对应图标变红 | 等待维修 |
| 舵机损坏 | 无法转向 | 紧急情况 |

### 4.8 战斗操作快捷键总结

| 操作 | 按键 | 优先级 |
|------|------|--------|
| 加速 | W | 高 |
| 减速 | S | 高 |
| 左转 | A (按住) | 高 |
| 右转 | D (按住) | 高 |
| 开火 | 鼠标左键 | 最高 |
| 锁定目标 | Ctrl | 高 |
| 望远镜 | Shift | 中 |
| 切HE弹 | 1 | 中 |
| 切AP弹 | 2 | 中 |
| 鱼雷 | 3 | 中 |
| 烟雾 | 4 | 高 (被发现时) |
| 维修 | 5 | 最高 (起火/进水时) |
| 水听/雷达 | 6 | 中 |
| 战斗机 | 7 | 低 |

## 八、状态检测规则

### 8.1 港口 (Port) 检测

```python
# 特征组合
is_port = (
    orange_button_ratio > 0.01 and      # 橙色按钮存在
    minimap_red_ratio < 0.002 and       # 无敌人 (小地图无红色)
    has_ship_carousel and               # 底部有舰船列表
    no_crosshair                        # 无准星
)
```

### 8.2 加载 (Loading) 检测

```python
# 特征组合
is_loading = (
    has_team_lists and                  # 有队伍列表
    no_minimap and                      # 无小地图
    no_crosshair and                    # 无准星
    brightness between 80-160 and       # 亮度中等
    orange_ratio < 0.005                # 无操作按钮
)
```

### 8.3 战斗 (Battle) 检测

```python
# 特征组合
is_battle = (
    minimap_blue_ratio > 0.2 or         # 小地图有蓝色 (海面)
    minimap_red_ratio > 0.005 or        # 小地图有红色 (敌人)
    team_panels_visible or              # 有队伍面板
    crosshair_std > 15                  # 有准星 (高对比度)
)
```

### 8.4 结算 (Results) 检测

```python
# 特征组合
is_results = (
    has_horizontal_lines > 15 and       # 多水平线 (表格)
    orange_ratio > 0.005 and            # 有操作按钮
    minimap_visible                     # 小地图可见
)
```

## 九、那不勒斯 (Napoli) 舰船参数

当前配置舰船: **那不勒斯** (意大利巡洋舰 T10)

| 参数 | 值 | 说明 |
|------|-----|------|
| 类型 | CA (重巡洋舰) | - |
| 等级 | X (10级) | 最高等级 |
| 血量 | 55,500 | 中等 |
| 最高速 | 36节 | 较快 |
| 鱼雷射程 | 8公里 | 近距离 |
| 副炮射程 | 5公里 | 近距离交战 |
| 检测距离 | 11.5公里 | 中等隐蔽 |
| 装甲角度 | 30度 | 魔鬼三角 |

### 战术特点

1. **近距离交战**: 副炮射程5km，适合冲脸

## 十三、注意事项

### 13.1 输入限制

- **鼠标**: WoWS使用Raw Input，标准SendInput无效
- **键盘**: `keyboard`库的SendInput可绕过过滤
- **解决方案**: 使用Interception驱动 (需管理员安装+重启)

### 13.2 分辨率适配

- 配置文件中 `game.resolution` 需与实际分辨率匹配
- 小地图位置: 右下角约15%区域
- HUD底部: 约底部10%区域

### 13.3 VLM集成

- VLM间隔: 3-5秒 (后台线程)
- 主循环: 10fps (安全检查+执行)
- 降级链: VLM → 上次有效决策 → 规则引擎 → 紧急停止
