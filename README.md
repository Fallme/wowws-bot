# 战舰世界自动战斗控制台

这是一个在 Windows 本地运行的实验工具。用户在网页控制台选择舰船、战斗模式和停止条件后，程序会自动完成启动游戏、港口检查、选择舰船、加入战斗、战斗控制、结算以及下一局。

> 最简单的使用方式：下载项目，解压，然后双击 `one_click_run.bat`。不需要手动输入 Python 命令。

## 一、安装前准备

只需要准备：

- Windows 10 或 Windows 11；
- 64 位 Python 3.11，安装时勾选 **Add Python to PATH**；
- Steam 版或 WG Game Center 版《战舰世界》；
- 首次安装依赖时能够联网。

建议把项目解压到普通磁盘目录，例如：

```text
E:\wowws_bot\
```

不要直接在压缩包内运行，也不建议放在桌面、OneDrive 同步目录或包含特殊符号的深层目录中。

## 二、下载与一键启动

### 普通用户：下载 ZIP

1. 在 GitHub 项目页面点击 **Code → Download ZIP**。
2. 将 ZIP 完整解压到一个新文件夹。
3. 双击项目根目录中的 `one_click_run.bat`。

第一次运行会自动创建项目专用环境、安装 OCR 和运行依赖，然后打开：

```text
http://127.0.0.1:8765/
```

首次安装通常需要几分钟。以后仍然只双击 `one_click_run.bat`；控制台已经运行时，它只会重新打开网页，不会重复启动服务。如果依赖不完整，也会自动进入修复安装。

### 熟悉 Git 的用户

```powershell
git clone https://github.com/Fallme/wowws-bot.git
cd wowws-bot
.\one_click_run.bat
```

以后更新：

```powershell
git pull --ff-only
.\one_click_run.bat
```

## 三、开始自动战斗

1. 登录 Steam 或 WG Game Center；游戏可以提前打开，也可以让控制台自动启动。
2. 在“游戏客户端”中选择 **Steam** 或 **WG Game Center**。控制台会从注册表、客户端配置和常见安装目录自动检索路径，不需要手动填写。
3. 选择“联合作战”或“非对称作战”。
4. 选择预设舰船；自定义舰船时，名称必须与港口显示完全一致，并填写副炮射程。
5. 设置停止条件：完整局数、运行时长或不限。
6. 按需勾选“快速战斗”或“完成后关闭游戏”。
7. 点击 **开始自动战斗**。

客户端按钮下会显示检测到的路径；如果当前选择的客户端尚未找到，启动时会在实时日志中给出明确原因。WG Game Center 模式不会自动回退到 Steam，避免启动错误账号或错误区服。

启动后，同一个主按钮会根据状态自动变成：

```text
开始自动战斗 → 暂停 → 继续
```

右侧的 **终止任务** 会结束本次计划，终止后不能继续；临时离开请使用“暂停”。

## 四、暂停与人工操作

- 单纯移动或点击鼠标不会触发自动暂停。
- 按键盘或切换到其他窗口会暂停新的自动操作。
- 只要用户仍在持续操作，程序不会强行切回游戏。
- 停止操作并连续静默 5 秒后，程序才会尝试返回游戏，并从当前画面重新识别流程。
- 持续操作达到 20 秒后会锁定暂停，必须回到网页点击 **继续**。
- 在网页主动点击“暂停”后，也必须点击“继续”才会恢复。

切屏、键盘介入、自动恢复和手动继续都会显示在实时日志中。恢复时不会沿用暂停前的旧按钮或旧页面，而是重新判断当前处于战斗、结算还是港口。

## 五、控制台怎么看

- **当前状态**：任务现在处于启动、准备、战斗、结算、回港还是暂停阶段。
- **地图区域**：开局打开 M 地图时锁定本局山体和占领点；自身位置、白色航向箭头和敌舰位置由右下角小地图持续更新。
- **舰船状态**：生命、火灾、进水、航速、舵位以及 R/其他消耗品状态。
- **实时日志**：建议排查问题时先看最后几行；不再显示单独的“问题处理后重试”按钮。
- **本组累计**：完整战斗的银币、舰船经验、全局经验、局数和累计用时。

## 六、两种运行方式

### 完整对局

正常等待战斗结束，读取结算数据，然后优先点击“继续战斗”。如果结算页不能直接继续，会自动回港，再从港口入口开始下一局。

### 快速战斗

勾选后，单局达到 5 分钟、确认沉没或离开战斗 HUD 时会退出本局并继续下一局。快速战斗计入计划局数，但不统计收益和胜负。

“完成后关闭游戏”只会在整组计划正常完成时生效；暂停、手动终止或异常不会关闭游戏。

## 七、常见问题

### 双击后没有打开网页

先等待首次安装完成，也可以手动打开 `http://127.0.0.1:8765/`。若命令窗口提示找不到 Python，请安装 64 位 Python 3.11 后重新双击。

### 安装依赖失败

检查网络后再次运行 `one_click_run.bat`。脚本会复用已经安装成功的内容。NVIDIA OCR 组件安装失败时会自动使用 CPU，不影响基本运行。

### 显示“游戏画面不可用”

确认游戏没有最小化，游戏和控制台使用相同的 Windows 权限运行，并等待日志重新绑定游戏窗口。不要同时启动多个控制台。

### 想更新程序

使用 Git 的用户执行 `git pull --ff-only`；下载 ZIP 的用户重新下载并解压到新文件夹。个人运行数据默认保存在项目内的 `data/` 和 `runtime/`，这些目录不会上传到 Git。

## 八、数据与隐私

以下内容只保存在本机，并已排除在 Git 之外：

```text
data/                          控制台设置、任务历史和运行状态
runtime/screenshots/runs/      每局诊断截图和结构化事件
runtime/screenshots/manual/    手动截图
runtime/ocr_reports/           OCR 离线测试报告
training_assets/user_captures/ 用户反馈截图
```

需要释放空间时，可在任务停止后使用控制台的“清理截图”。

## 开发验证

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe .\tools\simulate_screenshot_scenarios.py
```

离线截图回放不会查找游戏窗口，也不会发送键盘或鼠标操作。

## 使用提醒

本项目仅用于本地研究与受监督测试。游戏自动化可能违反服务条款并带来账号风险；程序不会规避反作弊，也不会在画面、输入或状态无法确认时盲目继续操作。
