# 战舰世界副炮流自动化 Bot

## 项目简介

这是一个基于 Python 的战舰世界（World of Warships）自动化挂机工具，专为 Steam 中文客户端设计。Bot 采用**副炮流**战术，支持波美拉尼亚（Pommern）和那不勒斯（Napoli）两艘战舰，能够在非对称作战（人机）模式下全自动完成从匹配到战斗再到下一局的完整循环，且**完全不影响用户的正常电脑操作**。

## 核心特性

### 后台运行，零干扰

Bot 的最大亮点是**完全后台运行**。它通过 Windows API 的 PostMessage 机制向游戏窗口发送点击消息，通过虚拟 Xbox 360 手柄（vgamepad + ViGEmBus 驱动）控制战斗中的航行和射击。整个过程中，用户的真实鼠标和键盘完全不受影响——你可以一边挂机打人机，一边正常办公、浏览网页、写代码，两者互不干扰。

### 副炮流自动战斗

Bot 实现了完整的副炮流战斗逻辑：

1. **自动航行**：通过小地图上的红色像素检测敌方战舰位置，自动转向并全速冲向最近的敌人
2. **副炮锁定**：进入副炮射程后，自动发送锁定指令，让副炮集火目标，大幅提升命中率
3. **主炮射击**：检测装填条绿色状态，装填完成后自动开火
4. **鱼雷发射**（波美拉尼亚专属）：在近距离自动发射鱼雷，增加爆发伤害
5. **烟雾释放**（那不勒斯专属）：血量低于 50% 时自动释放烟雾，提升生存能力
6. **鱼雷规避**：通过小地图检测黄色鱼雷轨迹，自动执行 S 型机动规避

### 智能图像识别

Bot 内置了一套基于 OpenCV 的实时图像识别系统：

- **敌舰检测**：HSV 色彩空间过滤小地图上的红色像素点，形态学处理去除噪点，轮廓检测定位每艘敌舰
- **鱼雷检测**：黄色像素过滤识别敌方鱼雷轨迹
- **装填状态**：绿色像素占比检测主炮/鱼雷是否装填完毕
- **血条检测**：通过血条像素宽度计算当前血量百分比
- **战斗结束检测**：检测屏幕中央白色文字面积，判断是否出现结算界面

所有识别都在每次截图后实时计算，延迟极低（约 0.5 秒一个决策周期）。

### 多船配置

通过 YAML 配置文件支持不同战舰的参数切换：

| 参数 | 波美拉尼亚 | 那不勒斯 |
|------|-----------|---------|
| 类型 | IX级 德系战列舰 | X级 意系巡洋舰 |
| 副炮射程 | 11.4km | 10km |
| 主炮装填 | 26秒 | 16秒 |
| 鱼雷 | 有（6km射程） | 13.5km |
| 烟雾 | 无 | 有（HP<50%释放） |

切换船只需要修改 `main.py` 中的 `ship_key` 变量即可。

### 技术栈

| 技术 | 用途 |
|------|------|
| **mss** | 高速屏幕截图（~30fps），后台截取游戏窗口区域 |
| **OpenCV** | 实时图像识别，HSV 色彩过滤 + 轮廓检测 |
| **vgamepad + ViGEmBus** | 虚拟 Xbox 360 手柄，战斗中的航行/射击控制 |
| **Win32 API (ctypes)** | PostMessage 后台点击、窗口查找、DPI 感知 |
| **NumPy** | 图像矩阵运算加速 |

### 为什么选择这些技术

战舰世界使用 DirectX 渲染，传统的截图方式（PrintWindow）会得到黑屏，因此采用 **mss** 直接截取屏幕像素区域，即使窗口被遮挡也能正常截图。游戏使用 **DirectInput** 读取鼠标输入，常规的合成鼠标事件（pydirectinput、SendInput）无法到达游戏引擎，因此菜单操作改用 **PostMessage** 向窗口句柄直接发送消息，战斗控制则使用 **虚拟手柄**（已被 DirectX 识别为真实控制器）。

## 使用方法

### 环境准备

```bash
# 安装 ViGEmBus 驱动（虚拟手柄必需）
# 下载地址：https://github.com/ViGEm/ViGEmBus/releases

# 安装 Python 依赖
cd E:\aimemo\wowws-bot
pip install -r requirements.txt
```

### 运行

1. 启动战舰世界，进入港口界面，选择要使用的战舰
2. 打开一个**独立的** cmd 或 PowerShell 窗口（不要通过 Claude 运行）
3. 执行：

```bash
cd E:\aimemo\wowws-bot
python main.py
```

4. Bot 自动检测游戏窗口，开始后台挂机
5. 按 `Ctrl+C` 随时停止

### 注意事项

- Bot 运行时请**不要最小化游戏窗口**（窗口可以被其他窗口遮挡，截图不受影响）
- 建议游戏以**窗口化无边框**模式运行，分辨率与副屏匹配
- 首次使用可能需要在游戏设置中启用手柄支持
- Bot 会在每次战斗结束后自动进入下一局，可持续挂机

- **战术策略**：根据船型自动选择冲锋/游走/卡点等不同战术

- **统计面板**：记录每局伤害、命中率、存活率等数据
